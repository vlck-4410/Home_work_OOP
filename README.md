Этот проект представляет собой учебное приложение на Python для управления категориями и товарами интернет-магазина.
В нем реализованы ключевые концепции объектно-ориентированного программирования (ООП): инкапсуляция, наследование, полиморфизм, абстрактные классы, миксины, а также магические методы и автоматический подсчет метрик.

## Архитектура проекта

* **`src/`** — модуль с основной бизнес-логикой:
  * `classes.py` — реализация классов и иерархии:
    * `BaseProduct` — абстрактный базовый класс для всех товаров.
    * `Product` — базовый класс товара.
    * `Smartphone`, `LawnGrass` — специализированные классы-преемники `Product`.
    * `Category` — класс категории товаров с автоматическим подсчетом уникальных товаров и категорий.
    * `PrintMixin` — миксин для автоматического вывода информации о создаваемом объекте при его инициализации.
  * `read_file.py` — функция для чтения и десериализации данных из JSON-файла.
* **`data/`** — папка с исходными файлами данных (`products.json`).
* **`tests/`** — модуль с тестами:
  * `test_classes.py`, `test_read_file.py` — модульные тесты (`pytest`) для проверки работоспособности классов, магических методов, миксинов и логики обработки данных.

## Основной функционал и концепции ООП

1. **Инкапсуляция и свойства:**
   * Приватные атрибуты (например, `__price`) защищены от прямого изменения.
   * Доступ к цене реализован через геттер и сеттер `@price.setter` с проверкой валидности (запрет нулевой/отрицательной цены и подтверждение снижения цены).

2. **Наследование и абстракция:**
   * Абстрактный класс `BaseProduct` обязует все товары реализовывать необходимые методы.
   * Наследники `Smartphone` и `LawnGrass` расширяют базовую функциональность товара специфическими атрибутами (производительность, модель, память, цвет, страна-производитель, период прорастания и т.д.).

3. **Множественное наследование и миксины:**
   * `PrintMixin` подмешивается в классы товаров и выводит в консоль информацию об объекте с его аргументами сразу при создании (`repr`).

4. **Магические методы:**
   * `__str__` — строковое представление объектов товаров и категорий (форматированный вывод общего количества и цены).
   * `__add__` — сложение товаров одного типа с учетом их количества и стоимости (запрещено складывать товары разных классов, например `Smartphone` и `LawnGrass`).
