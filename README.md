Этот проект представляет собой учебное приложение на Python для управления категориями и товарами.
В нем реализованы базовые концепции объектно-ориентированного программирования (ООП), автоматический подсчет метрик (количество уникальных категорий и товаров), а также подгрузка исходных данных из файлов формата JSON.

## Архитектура проекта

* **`src/`** — модуль с основной бизнес-логикой, в нем реализованы:
    * (`classes.py`) — реализация классов `Product` (Товар) и `Category` (Категория).
    * (`read_file.py`) — функция для чтения и десериализации данных из JSON-файла.
* (`data`) — папка с исходными файлами данных (`products.json`).
* **`tests/`** — модуль с тестами.
    * (`test_classes.py`, `test_read_file.py`) — модульные тесты для проверки работоспособности кода.
