Этот проект представляет собой учебное приложение на Python для управления категориями и товарами интернет-магазина.
В нем реализованы ключевые концепции объектно-ориентированного программирования (ООП): инкапсуляция, наследование, полиморфизм, абстрактные классы, миксины, магические методы, а также обработка исключений и автоматический подсчет метрик.

## Архитектура проекта

* **`src/`** — модуль с основной бизнес-логикой:
  * `classes.py` — реализация классов и иерархии:
    * `BaseProduct` — абстрактный базовый класс для всех товаров.
    * `Product` — базовый класс товара с валидацией входных данных.
    * `Smartphone`, `LawnGrass` — специализированные классы-преемники `Product`.
    * `Category` — класс категории товаров с подсчетом метрик и расчетом средней стоимости.
    * `PrintMixin` — миксин для автоматического вывода информации о создаваемом объекте в консоль при инициализации.
  * `read_file.py` — функция для чтения и десериализации данных из JSON-файла.
* **`data/`** — папка с исходными файлами данных (`products.json`).
* **`tests/`** — модуль с тестами:
  * `test_classes.py`, `test_read_file.py` — модульные тесты (`pytest`) для проверки работоспособности классов, миксинов, исключений и логики обработки данных.

## Основной функционал и концепции ООП

1. **Инкапсуляция и свойства:**
   * Приватные атрибуты (например, `__price`, `__products`) защищены от прямого изменения.
   * Доступ к цене реализован через геттер и сеттер `@price.setter` с валидацией (запрет нулевой/отрицательной цены и проверка при снижении стоимости).

2. **Наследование и абстракция:**
   * Абстрактный класс `BaseProduct` обязует все товары реализовывать необходимые методы.
   * Дочерние классы `Smartphone` и `LawnGrass` расширяют функциональность специфическими атрибутами.

3. **Множественное наследование и миксины:**
   * `PrintMixin` подмешивается в классы товаров и автоматически выводит в консоль строку `repr` с именем класса и аргументами при создании объекта.

4. **Магические методы:**
   * `__str__` — понятное строковое представление объектов товаров и категорий.
   * `__add__` — сложение товаров одного типа с учетом количества и стоимости (сложение разных классов запрещено).

5. **Обработка ошибок и исключений (Exceptions):**
   * **Валидация при создании товара:** при попытке инициализации `Product` с нулевым или отрицательным количеством выбрасывается исключение `ValueError` ("Товар с нулевым количеством не может быть добавлен") с остановкой выполнения.
   * **Безопасный расчёт средней цены:** метод `middle_price()` в классе `Category` использует блок `try...except ZeroDivisionError` и корректно возвращает `0`, если в категории нет товаров.
